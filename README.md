# PaperDesk-Downloads

PaperDesk의 macOS 실행 파일을 배포하는 저장소입니다.

- [PaperDesk 0.2.0 다운로드](PaperDesk-0.2.0.zip?raw=true) · 빌드 21 · Apple Silicon, macOS 14 이상
- ZIP을 풀고 `PaperDesk.app`을 응용 프로그램 폴더에 옮겨 실행하세요.
- 이후에는 앱 메뉴 **PaperDesk → 업데이트… → GitHub**에서 새 버전을 확인하세요.
- 저장소가 비공개인 경우 이 저장소의 **Contents: Read** 권한이 있는 GitHub 토큰을 앱에 저장하세요.

0.2.0에서는 PDF 요약과 논문 질문의 추론 강도를 따로 선택할 수 있습니다. 기본값은 요약 High, 질문 Medium입니다. 로컬 폴더와 GitHub에서 업데이트할 수 있고, 배포 ZIP에서 개발 PC의 로컬 프로젝트 경로를 제거했습니다.
